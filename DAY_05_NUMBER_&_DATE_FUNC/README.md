
NUMBER & DATE FUNCTIONS in ORACLE SQL

*Purpose:

 1. Number functions are used to manipulate and perform operations on numeric datatype.
 
 2. We mostly use number functions like  ROUND(), TRUNC(), MIN(), MAX(), etc.
 
 3. Date functions are useful to data analyst to do daily cores.

 4. The date functions are as follows :
      i.  MONTHS_BETWEEN() → Returns the number of months between two dates.

     ii. ADD_MONTHS() → Adds a specified number of months to a date.
      
    iii. NEXT_DAY() → Returns the date of the next specified weekday after a given date.
      
     iv. LAST_DAY() → Returns the last day of the month for a given date.
      
      v. ROUND() → Rounds a date to the nearest specified unit, such as a month or year.
      
     vi. TRUNC() → Truncates a date to the beginning of a specified unit, such as a month or year.
