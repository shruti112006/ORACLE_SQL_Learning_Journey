
* MULTI-JOINS in SQL (Oracle SQL)
    A Multi-Join is used to combine data from three or more tables in a single SQL query using multiple JOIN conditions.
    
    - Combines data from three or more tables.
    - Uses multiple JOIN clauses to connect related tables.
    - Each JOIN specifies a condition using the ON clause.
    - Usually connects tables through primary key and foreign key relationships.
    - Can use different JOIN types such as INNER JOIN, LEFT JOIN and RIGHT JOIN in the same query.
    - Helps retrieve related information stored across multiple tables.

 
* NON-EQUI JOIN
     A Non-Equi Join is a type of join in which two tables are joined using comparison operators other than the equality operator (=), such as BETWEEN, >, <, >=, and <=.
    
    - Joins two or more tables using non-equality conditions.
    - Does not use the = operator in the join condition.
    - Commonly uses operators such as BETWEEN, >, <, >=, and <=.
    - Useful when matching values based on ranges or conditions.
    - Often used for salary grades, tax slabs, commission rates, and discount ranges.
