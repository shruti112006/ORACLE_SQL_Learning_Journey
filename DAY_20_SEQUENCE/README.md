
SEQUENCE in Oracle SQL
  - A SEQUENCE is a database object in Oracle SQL that automatically generates a series of numeric values, usually used to generate unique IDs for table records.

  - A sequence generates numbers independently of a table. It does not automatically insert values into a column. You use it in an INSERT statement or other SQL operations.

SYNTAX OF SEQUENCE : 

  CREATE SEQUENCE sequence_name

  START WITH initial_value
    
  INCREMENT BY increment_value
  
  MINVALUE minimum_value
  
  MAXVALUE maximum_value
  
  CYCLE | NOCYCLE
  
  CACHE | NOCACHE;


  - A. NEXTVAL : NEXTVAL generates and returns the next sequence value.

  - B. CURRVAL : CURRVAL returns the current value generated by the sequence in your current database session.
