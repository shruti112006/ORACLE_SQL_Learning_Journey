
Nested Control Statements in PL/SQL : 
   Nested control statements means using one control statement inside another control statement.

1. Nested IF Statement : When an IF statement is written inside another IF statement, it is called a Nested IF statement.

2. Nested LOOP Statement : When one loop is written inside another loop, it is called a Nested LOOP.

- Nested control statements allow one control statement inside another.

- They are used to implement complex business logic.

- Nested IF statements can have multiple levels.

- Nested loops are useful for processing multiple levels of data.

- Every nested block must have the appropriate closing statement, such as END IF or END LOOP.

- Nested loops can increase execution time if not designed properly.
