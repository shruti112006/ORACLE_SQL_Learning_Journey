
 SELF JOIN

A SELF JOIN is a type of join in which a table is joined with itself to retrieve related records within the same table.

- A table is joined with itself.
- Used when records in the same table have a relationship with each other.
- Requires table aliases to distinguish between the two instances of the same table.
- Can use INNER JOIN, LEFT JOIN, or other join conditions.
- Commonly used to find employee-manager relationships, hierarchical data, and comparisons between records in the same table.
