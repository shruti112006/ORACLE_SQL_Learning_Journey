
AGGREGATE_FUNCTIONS

Purpose :  This are the multi row in-built functions in SQL. These functions are used to get summarized results.

i. COUNT() → Returns the number of rows or non-NULL values in a column.

   * There are three ways to use COUNT() function such as,
   * COUNT(*) → Counts all rows in a table, including rows containing NULL values.
   * COUNT(column_name) → returns the number of non-NULL values in the specified column.
   * COUNT(DISTINCT column_name) → Counts only the unique, non-NULL values in the specified column.

ii. SUM() → Returns the total sum of numeric values in a column.

iii. AVG() → Returns the average of numeric values in a column.

iv. MIN() → Returns the minimum value in a column.

v. MAX() → Returns the maximum value in a column.

vi. STDDEV() → Returns the standard deviation of numeric values in a column.

vii. VARIANCE() → Returns the statistical variance of numeric values in a column.
