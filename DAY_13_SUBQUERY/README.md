
SUBQUERY  : A Subquery is a query written inside another SQL query. It is used to retrieve data from one query and use that result in the outer query.
            A Subquery is also known as an Inner Query or Nested Query.
  
  - A query written inside another SQL query is called a Subquery.
  
  - The inner query executes to provide a result to the outer query.
  
  - The outer query uses the result of the inner query to retrieve the required data.
  
  - Subqueries are enclosed within parentheses ().
  
  - Subqueries can be used with SELECT, INSERT, UPDATE, and DELETE statements.
  
  - They can be used with operators such as =, >, <, IN, ANY, ALL, and EXISTS.
  
  - A Subquery can return a single value, multiple values, or multiple rows and columns, depending on its structure.
  
  - Subqueries can be nested inside other subqueries.
