
* PL/SQL (Procedural Language/SQL) is Oracle's procedural extension of SQL. It combines standard SQL statements with programming language features such as variables, conditions, loops, procedures, and functions.

- SQL is used to communicate with a database (retrieve, insert, update, and delete data).

- PL/SQL allows you to write programming logic along with SQL statements to perform complex operations.

- PL/SQL is mainly used with Oracle Database.

* PL/SQL helps us to:

1. Execute multiple SQL statements together.

2. Declare and use variables.

3. Apply conditions using IF-ELSE.

4. Perform repetitive tasks using loops.

5. Handle errors using exception handling.

6. Create stored procedures, functions, and triggers.

7. Automate database operations.

PL/SQL contains three blocks such as DECLARE , BEGIN , EXCEPTION  & END. Where as  DECLARE AND EXCEPTION block are optional blocks.

- DECLARE -> variable declaration is done

- BEGIN -> Actual logic of the code, SQL query is written.

- EXCEPTION -> This block handles the exceptions raise while execution the code.

- END -> This keyword shows the ending of the PL/SQL code.
