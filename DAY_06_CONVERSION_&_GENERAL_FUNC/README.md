
CONVERSION & GENERAL FUNCTIONS

*Purpose :

1. Conversion Functions (Oracle SQL)
        are used to convert data from one datatype into another datatype. 

      i. TO_CHAR() → Converts a date or number into a character string.
      
      ii. TO_DATE() → Converts a character string into a date.
      
      iii. TO_NUMBER() → Converts a character string into a number.
      
      iv. CAST() → Converts a value from one data type to another.

3. General Functions (Oracle SQL)
      are used to handle NULL values in the dataset.
   
      i. NVL() → Replaces a NULL value with a specified alternative value.
      
      ii. NVL2() → Returns one value if the expression is NOT NULL and another value if it is NULL.
      
      iii. NULLIF() → Returns NULL if two expressions are equal; otherwise, returns the first expression.
      
      iv. COALESCE() → Returns the first non-NULL expression from a list of expressions.
      
      v. DECODE() → Compares an expression with specified values and returns the corresponding result.
      
      vi. CASE() → Evaluates conditions and returns a result based on the first matching condition.
