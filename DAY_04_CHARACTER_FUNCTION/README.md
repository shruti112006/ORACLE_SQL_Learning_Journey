
CHARACTER FUNCTIONS

PURPOSE : 
CHARACTER FUNCTIONS are in-built functions for string datatype. They are divided into 2 types namely,

i. CASE MANIPULATION FUNCTIONS -> Used to manipulate the case of string
    such as UPPER, LOWER ,INITCAP

&

ii. CHARACTER MANIPULATION FUNTION -> Used to perform operations on the string datatype.
    such as SUBSTR, INSTR, FIND, STRIP, TRIM , CONCAT
