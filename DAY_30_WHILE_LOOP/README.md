
WHILE LOOP in PL/SQL
A WHILE LOOP is an iterative control statement in PL/SQL that repeatedly executes a block of statements as long as a specified condition is TRUE.

- In simple words, WHILE LOOP checks the condition first. If the condition is TRUE, the loop executes; if FALSE, the loop terminates.

- It is useful when we don't know exactly how many times a loop needs to execute.

* Syntax of WHILE LOOP

WHILE condition

LOOP

  statements;

END LOOP;

Explanation:

- WHILE: Starts the loop.

- condition: Checks whether the condition is TRUE or FALSE.

- LOOP: Starts the execution block.

- statements: Contains the code to be executed.

- END LOOP: Terminates the loop.
